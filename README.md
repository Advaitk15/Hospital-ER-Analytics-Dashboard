# 🏥 Hospital Emergency Room Analytics Dashboard

 📌 Project Overview

The **Hospital Emergency Room Analytics Dashboard** is a data analytics project built using Microsoft Power BI. It provides an interactive view of hospital emergency room operations, helping users understand patient demographics, admission patterns, waiting times, and patient satisfaction.

The dashboard converts healthcare data into visual insights that can help identify operational trends and support data-driven decision-making.

 🎯 Project Objectives

- Analyze patient demographics, including age, gender, and race.
- Understand patient admission and waiting status.
- Monitor patient waiting times and satisfaction scores.
- Explore monthly trends in emergency room visits.
- Provide patient-level details for more detailed analysis.
- Present key findings through interactive visualizations.

📊 Dashboard Features

 1. Monthly View
Explore monthly trends and analyze emergency room performance using patient-related metrics and visualizations.

 2. Patient Details
Examine patient-level information, including patient ID, name, gender, age, and department referral.

3. Key Takeaways
Review important findings from the dashboard to understand patient flow, waiting times, admission patterns, and satisfaction.

## 📈 Key Performance Indicators (KPIs)

The following KPIs can help evaluate emergency room performance, provided the required fields are available in the dataset.

| KPI | Description |
|---|---|
| Total Patients | Total number of patient visits or records |
| Average Waiting Time | Average time patients wait before being attended to |
| Patient Admission Rate | Percentage of patients admitted to the hospital |
| Average Satisfaction Score | Average recorded patient satisfaction score |
| Patient Attendance Status | Distribution of patients who have been attended to versus those still waiting |
| Department Referrals | Number of patients referred to each department |

### Example KPI Calculation

**Patient Admission Rate**

\[
\text{Admission Rate} = \frac{\text{Number of Admitted Patients}}{\text{Total Patients}} \times 100
\]

This KPI measures the percentage of recorded patient visits that result in hospital admission.
